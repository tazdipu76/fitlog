Project Name:
FitLog — A Dark, No-Nonsense Gym Companion & Workout Library

Short Description:
FitLog is a modern, dark-themed, and fully responsive web application built for fitness enthusiasts. It enables users to browse a comprehensive workout library, build daily routines with a strict cap of five exercises, and track fitness metrics effortlessly.

Technologies Used:
1.Frontend Framework: Next.js (App Router)

2.Styling: Tailwind CSS, DaisyUI

3.Language: TypeScript

4.State Management & Persistence: React Context API & LocalStorage

5.Notifications & Icons: React Hot Toast, Lucide React

5 Key Features of the Project:
1.Interactive Workout Library & Details: Browse various gym workouts and view detailed specifications such as duration, calorie burn estimate, and user ratings.

2.Daily Plan Builder (Cap of 5): Intuitively select and lock in up to five exercises to form your structured plan for the day.

3.Saved Lifts & Favorites: Bookmark and save favorite exercises to access and review them later via a dedicated saved tab.

4.Metrics & Progress Tracker: A real-time dashboard summary displaying total selected exercises, cumulative duration (minutes), and total estimated calories burned.

5.Persistent Local Storage: Seamlessly preserves daily plans, completion statuses, and saved workouts across browser refreshes and sessions.
